# 🎬 SmartTheater — Web-Based Movie Theater Application

**SmartTheater** is a full-stack web application for managing a smart movie theater booking system. It was developed as a **Final Project** for a Software Engineering course, applying real-world software engineering principles including requirements analysis, system design, and implementation.

---

## ✨ Features

- Browse currently showing movies
- Select seats and book tickets
- Manage theater schedules and screenings
- Responsive web interface with rich styling

---

## 🚀 Getting Started

### Prerequisites
- Java JDK 8+
- A Java-capable web server (e.g. Apache Tomcat)
- A modern web browser

### Running the Application

1. Clone the repository:
   ```bash
   git clone https://github.com/agrrr/SmartTheater.git
   ```
2. Open the project in your IDE (IntelliJ IDEA or Eclipse recommended).
3. Deploy to a local Tomcat server.
4. Navigate to `http://localhost:8080/SmartTheater` in your browser.
